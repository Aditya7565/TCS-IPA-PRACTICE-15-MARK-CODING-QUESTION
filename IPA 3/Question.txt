TRUCK AND DRIVER MANAGEMENT SYSTEM
==================================

QUESTION DESCRIPTION
--------------------

Create a Truck and Driver Management System using Java.

You need to create two classes:

1. Driver
2. Truck

You also need to create a Solution class containing a static method to find trucks based on the total distance traveled.

--------------------------------------------------
CLASS 1: DRIVER
--------------------------------------------------

Create a class named Driver with the following attributes:

id          : int
name        : String
contact     : String
experience  : float

Create:

1. A parameterized constructor to initialize all the attributes.
2. Getter methods for all the attributes.

Required getter methods:

getId()
getName()
getContact()
getExperience()


--------------------------------------------------
CLASS 2: TRUCK
--------------------------------------------------

Create a class named Truck with the following attributes:

id                         : int
name                       : String
totalMilesTraveledByTruck  : float
driver                     : Driver

Create:

1. A parameterized constructor to initialize all the attributes.
2. Getter methods for all the attributes.

Required getter methods:

getId()
getName()
getTotalMilesTraveledByTruck()
getDriver()


--------------------------------------------------
METHOD TO IMPLEMENT
--------------------------------------------------

Create the following static method inside the Solution class:

public static Truck[] getAllTruckWithDistance(Truck[] truck, float distance)


METHOD REQUIREMENTS
-------------------

The method should perform the following operations:

1. Check all the trucks in the given Truck array.

2. Select only those trucks whose
   totalMilesTraveledByTruck is greater than or equal to
   the given distance.

   Condition:

   totalMilesTraveledByTruck >= distance

3. If no truck satisfies the condition, return null.

4. If one or more trucks satisfy the condition, sort those trucks
   according to the driver's experience.

5. The sorting should be in DESCENDING order of driver's experience.

   Example:

   Driver Experience:

   8.5
   7.0
   5.5
   3.0

6. Return the sorted Truck array.


--------------------------------------------------
MAIN METHOD INPUT
--------------------------------------------------

The main method should take input using Scanner.

First input:

Number of trucks (n)

Then for each truck, take the following details:

1. Truck ID
2. Truck Name
3. Total Miles Traveled by Truck
4. Driver ID
5. Driver Name
6. Driver Contact
7. Driver Experience

After entering all truck details, take:

8. Distance


--------------------------------------------------
INPUT FORMAT
--------------------------------------------------

First line:
Number of trucks

For every truck:

Truck ID
Truck Name
Total Miles Traveled
Driver ID
Driver Name
Driver Contact
Driver Experience

After all trucks:

Distance


--------------------------------------------------
OUTPUT FORMAT
--------------------------------------------------

If no truck has traveled the required distance, print:

No truck found


Otherwise, for every matching truck print:

Truck ID
Truck Name
Total Miles Traveled
Driver ID
Driver Name


--------------------------------------------------
IMPORTANT CONDITIONS
--------------------------------------------------

1. A truck is selected when:

   totalMilesTraveledByTruck >= distance

2. Sort selected trucks by driver experience.

3. Sorting must be in descending order.

4. If no truck matches, return null.

5. Driver is an object inside the Truck class.

6. To get driver experience from a Truck object, use:

   truck.getDriver().getExperience()
